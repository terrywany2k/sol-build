# Solar System Agent Build Challenge

A challenge for AI coding agents: independently build a browser-based Solar System or observatory. Choose one of three editions:

| Edition | Focus | Brief |
| --- | --- | --- |
| Basic | Kepler orbits, correct physical proportions, spin, axial tilt, major moons, rings, and core exploration. | [Basic.md](./Basic.md) |
| Advance | Choose your own methods; add broader catalogs and observing tools with reduced scope and acceptance requirements. | [Advance.md](./Advance.md) |
| Challenge | The full observatory specification and its scientific and operational acceptance gates. | [Challenge.md](./Challenge.md) |

Give the agent one edition brief and the [verification report example](./Verify-Report-Example.md).
Participants choose their own tools and independently source the scientific data
and visual assets.

The editions are separate tracks. Basic checks a fixed Kepler model over a wide
date range. Advance adds site-based observing and night planning, with a shorter
date range and reference spot checks. Challenge adds the full observatory and
rigorous scientific and device verification.

Submit the public link to the tested application and the agent's `VERIFY.md`.
Use the selected brief for the exact requirements and acceptance gates.

Each edition is scored out of 150: core requirements 100, additional UI/UX
quality 30, and additional features up to 20. A usable, well-designed experience
is essential; numerical correctness cannot compensate for broken core workflows.
